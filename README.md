# COMM514 MSc Research Project

MSc Data Science research project at the University of Exeter.

## Research direction

This project investigates the reliability of large language model (LLM) outputs, with a particular focus on hallucination detection and verification.

The current plan is to use locally hosted language models through Ollama and to develop a reproducible Python-based evaluation pipeline. Existing methods may be used as baselines, while the final project is expected to explore an original verification or detection approach.

## Current stage

Initial project setup and benchmark dataset selection.

The HaluEval QA dataset has been selected as the first benchmark candidate for pilot experiments. Other datasets may be considered later as the project develops.

## Project structure

- `data/raw/` – original benchmark data
- `data/processed/` – processed or sampled datasets
- `src/` – Python source code
- `results/` – experimental outputs and evaluation results
- `notes/` – research notes and project records
